# lucid7132 — Portfolio

데이터 분석과 Python 프로젝트를 소개하는 개인 포트폴리오 사이트입니다.

## 구성

- `index.html` — 메인 포트폴리오
- `css/style.css` — 디자인과 반응형 스타일
- `js/main.js` — 메뉴, 프로젝트 렌더링, 스크롤 인터랙션
- `data/projects.json` — 프로젝트 데이터
- `404.html` — 잘못된 주소 안내

## 로컬에서 보기

```bash
python -m http.server 8000
```
